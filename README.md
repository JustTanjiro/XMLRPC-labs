# ЛР № 3 — вычисления на основе взаимодействия сервисов

Готовый проект на основе тетрадей ЛР № 1–2. Все программные ячейки без комментариев.

## Файлы

- `xmlrpc_server.ipynb` — основной сервер, порт **8008**;
- `xmlrpc_proxy_server.ipynb` — прокси и Rate Limiting, порт **8009**;
- `xmlrpc_stats2_server.ipynb` — сервер статистики и SQLite `log.db`, порт **8019**;
- `xmlrpc_client.ipynb` — проверки всех функций, журнала, фильтров и Rate Limiting;
- `xmlrpc_stats_server.ipynb` — исходный сервер статистики ЛР № 2, сохранён для истории;
- `bad_boys2.csv`, `Jellyfish.jpg`, `11.bmp` — входные данные.

## Запуск

Откройте Jupyter Notebook из папки проекта: `jupyter notebook`.

1. Запустите все программные ячейки `xmlrpc_stats2_server.ipynb` (порт 8019).
2. В отдельном ядре запустите `xmlrpc_server.ipynb` (порт 8008).
3. В третьем ядре запустите `xmlrpc_proxy_server.ipynb` (порт 8009).
4. Выполняйте ячейки `xmlrpc_client.ipynb` последовательно, оставляя первые три сервера работающими.

Используйте разные ядра для каждого сервера. **Старый** `xmlrpc_stats_server.ipynb` на порту 8018 запускать не требуется. После остановки сервера не запускайте второй экземпляр на том же порту.

Установка пакетов: `pip install notebook numpy pandas pillow matplotlib` (SQLite, Git и XML-RPC входят в стандартную библиотеку Python или устанавливаются отдельно как Git).

## Дополнительное задание

Поле `duration_seconds` содержит сумму `wait_seconds + execution_seconds`. В клиентской итоговой таблице показывается объединённое время обработки.

## Проверки

Шесть последовательных `ping()` вызовов: первые пять проходят без лимитной паузы, шестой дожидается освобождения слота. Событие `too_many_requests` записывается отдельно. Фильтры SQLite включают название операции, время события и длительность.

Для проверки отказоустойчивости остановите ядро сервера статистики (8019), затем выполните последнюю тестовую ячейку клиента. Основной сервер и прокси должны продолжить отвечать. После запуска статистики сохранение событий возобновится.
